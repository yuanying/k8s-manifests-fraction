## 9. 手順書との差、気づいたこと

- `Container <名前> definition changed, will be restarted` は kubelet の journal（既定の verbosity）には出ず、イベント（reason `Killing`）に出る。runbook §4.3 の 10・§8.4 の書き方を直す
- 確認を kubelet の起動の 25 秒後に一度流したところ、kube-apiserver と smart-exporter はまだ止まりかけ（30 秒の猶予の中）で restartCount が増えていなかった。runbook のとおり 1 分ほど待ってから数えるのが要る
- arm64 の control-plane でも、dev の amd64 と同じ形で全コンテナが 1 回ずつ再起動した（runbook の「dev で確かめていないもの」の 1 つ目）
